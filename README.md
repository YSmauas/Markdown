אין שרת, אין התקנה ואין ספריות חיצוניות: פותחים את הקובץ בדפדפן ועובדים.

> [!NOTE]
> כל העיבוד מתבצע בדפדפן שלך. שום תוכן לא נשלח לשום מקום.

## תכונות

**קריאה ותצוגה**

- תצוגה מעוצבת חיה בצד העורך, בעיצוב GitHub, במצב בהיר וכהה לפי הגדרות המכשיר.
- מצב קריאה שמסתיר את העורך.
- כיוון תצוגה: אוטומטי, עברית (ימין לשמאל) או אנגלית (שמאל לימין).
- הגדלה והקטנה של התצוגה בלבד, בין 70% ל-180%, בלי לשנות את גודל העורך.
- תוכן עניינים בסגנון GitHub: אייקון רשימה בסרגל מעל התצוגה פותח תפריט כותרות, ולצד כל כותרת יש אייקון קישור (עוגן).
- ספירת מילים.
- הערות בסגנון GitHub (Alerts): `NOTE`, `TIP`, `IMPORTANT`, `WARNING`, `CAUTION`.

**כתיבה ועריכה**

- סרגל כלים: הדגשה, נטוי, קו חוצה, כותרת, ציטוט, קוד בתוך שורה, בלוק קוד, קטע מתקפל, קישור, תמונה, רשימה וטבלה.
- חיפוש והחלפה, כולל "החלף הכול" וספירת תוצאות.
- המשך אוטומטי של רשימות בלחיצה על Enter (תבליטים, מספור ורשימות משימות).
- מצב מיקוד: רק העורך, כולל מעבר למסך מלא.
- יישור כל שורה לפי השפה שבה היא כתובה, כך שטקסט עברי ואנגלי מעורב נראה תקין.

**שמירה וייצוא**

- שמירה ישירה לאותו קובץ שנפתח, בלי להוריד אותו מחדש (בדפדפנים נתמכים).
- שמירה אוטומטית לקובץ, אפשר לכבות.
- טיוטה שנשמרת אוטומטית בדפדפן ומשוחזרת בפתיחה הבאה.
- פתיחה מחדש של הקובץ האחרון בלחיצה אחת.
- ייצוא ל-HTML עצמאי.
- הדפסה או שמירה כ-PDF דרך הדפדפן, בעיצוב נקי.

**ניידות**

- פריסה מותאמת לנייד, עם מעבר בין לשוניות "תצוגה" ו"עריכה".
- גרירת קובץ `.md` לתוך הדף פותחת אותו.

## שני סגנונות: GitHub ומתמחים טופ

מתג בראש הדף מחליף בין שני סגנונות. הבחירה נשמרת בדפדפן.

- **GitHub** הוא ברירת המחדל: עיצוב ותחביר של GitHub.
- **מתמחים טופ** מעצב את התצוגה כמו פוסט בפורום ומוסיף סרגל כלים ותחביר לפי [המדריך של הפורום](https://mitmachim.top/topic/7036/):

| תחביר | תוצאה |
|---|---|
| `:::` בשורה נפרדת, תוכן, ושוב `:::` | ספוילר |
| `%(#e03131)[טקסט]` | צבע טקסט |
| `***טקסט***` (או `Ctrl+U`) | קו תחתון (בסגנון GitHub זה מודגש ונטוי) |
| `-> טקסט <-` / `-> טקסט ->` / `<- טקסט <-` | יישור למרכז / לימין / לשמאל |
| `!!! info [כותרת]: טקסט` | התראה (`info`, `important`, `warning`) |
| `IIטקסטII` (בלי רווחים) | טקסט מוסתר מאורחים |
| `°fa-info°(הסבר)` | הסבר בריחוף |
| `## כותרת` | כותרת עם רקע כהה |
| `@שם-משתמש` | תיוג (מוצג בצבע) |
| `&nbsp;` | רווח נוסף |
| `###### א` ואז `[טקסט](#א)` | תפריט קישורים פנימי |

התחביר של הפורום בנוי על תוסף NodeBB, והדף מדמה את התצוגה שלו. ייתכנו הבדלים קטנים מהתצוגה בפורום עצמו, ולכן כדאי לבדוק פוסט חשוב בתצוגה המקדימה של הפורום לפני פרסום.

## התחלה מהירה

1. הורידו את הקובץ `index.html` (או `markdown_reader_mobile_plus.html`, לפי השם שבחרתם).
2. פתחו אותו בדפדפן בלחיצה כפולה.
3. לחצו על **פתיחת קובץ .md** או התחילו לכתוב מיד.

אין צורך באינטרנט אחרי שהקובץ אצלכם.

## שמירה ועריכת קבצים

הדף מנסה לשמור בדרך הנוחה ביותר שהדפדפן מאפשר.

### כתיבה ישירה לקובץ

בדפדפנים שתומכים ב-[File System Access API](https://developer.mozilla.org/docs/Web/API/File_System_Access_API) (כרום ואדג' במחשב):

1. לוחצים **פתיחת קובץ .md** ובוחרים קובץ.
2. הדפדפן מבקש הרשאת כתיבה לקובץ. יש לאשר.
3. מרגע זה כל שינוי נשמר לאותו קובץ כעבור פחות משנייה (כשהתיבה "שמירה אוטומטית" מסומנת), או ידנית ב-`Ctrl+S`.
4. בחלונית העורך מוצג המצב: **● שינויים לא נשמרו** או **✓ נשמר בקובץ**.

כפתור **שמירה בשם** (`Ctrl+Shift+S`) יוצר קובץ חדש או שומר למקום אחר.

### דפדפנים בלי תמיכה בכתיבה ישירה

- פתיחת קובץ נעשית דרך בורר הקבצים הרגיל.
- **שמירה** מורידה קובץ `.md` חדש.
- הטיוטה נשמרת אוטומטית בדפדפן (`localStorage`), כך שסגירה בטעות לא מאבדת עבודה.

### טיוטה ושחזור

- כל שינוי נשמר כטיוטה בדפדפן, גם כשיש כתיבה ישירה לקובץ.
- בפתיחה הבאה של הדף מוצגת הטיוטה האחרונה.
- **מסמך חדש** מנקה את העורך (לאחר אישור).

### פתיחה מחדש של הקובץ האחרון

בדפדפנים נתמכים הדף זוכר את הקובץ האחרון שנפתח (ב-IndexedDB) ומציג כפתור **פתיחה מחדש**. הדפדפן יבקש שוב אישור כתיבה בכל פעם. זו מגבלת אבטחה של הדפדפן ולא של הדף.

| `Enter` על פריט ריק | סיום הרשימה |

ב-Mac משתמשים ב-`Cmd` במקום `Ctrl`.

## תחביר Markdown נתמך

- כותרות `#` עד `######`
- **הדגשה**, *נטוי*, ~~קו חוצה~~ וקוד בתוך שורה
- קישורים, קישורים אוטומטיים (`<https://...>`) ותמונות
- רשימות מסודרות ולא מסודרות, ורשימות משימות (`- [x]`)
- ציטוטים והערות GitHub:

  ```md
  > [!WARNING]
  > זו אזהרה.
  ```

- טבלאות בסגנון GitHub, כולל יישור עמודות עם `:---:`
- בלוקי קוד מגודרים (` ``` ` או `~~~`)
- קו מפריד `---`
- תגיות HTML נבחרות: `<details>`, `<summary>`, `<kbd>`, `<mark>`, `<sup>`, `<sub>`, `<div>`, `<span>`, `<table>` ועוד.
  תגיות מסוכנות (`<script>`, `<iframe>` וכד'), מאפייני `style` ומאפייני אירועים (`onclick` וכד') מוסרים.

### תמונות

כפתור התמונה מוסיף ל-Markdown נתיב יחסי בלבד (למשל `![תיאור](./picture.png)`) ואינו מטמיע את התמונה בקובץ.
שמרו את התמונה ליד קובץ ה-Markdown, או עדכנו את הנתיב ידנית. כתובות `https://` ותמונות `data:image/...;base64` נתמכות גם הן.

## צביעת תחביר בבלוקי קוד

ציינו את השפה אחרי שלוש הגרשיים:

````md
```python
def greet(name):
    # ברכה
    return f"שלום {name}"
```
````

הצביעה מקומית לגמרי, בלי ספריות. היא מזהה הערות, מחרוזות, מספרים, מילות מפתח, קריאות לפונקציות ותגיות HTML.
היא עובדת היטב עם `python`, `js`, `ts`, `json`, `html`, `css`, `bash`, `sql`, `yaml` ושפות דומות.
בלוק בלי שפה, או עם `md` או `txt`, מוצג ללא צביעה.

> [!NOTE]
> זו צביעה כללית ולא ניתוח דקדוקי מלא של כל שפה. בשפות פחות נפוצות ייתכנו מילות מפתח שלא יצבעו.

## העלאה ל-GitHub Pages

1. צרו מאגר חדש ב-GitHub.
2. העלו אליו את קובץ ה-HTML ושנו את שמו ל-`index.html`, כדי שיוצג ככתובת הראשית.
3. העלו גם את `README.md` (קובץ זה).
4. במאגר: **Settings** ← **Pages**.
5. תחת **Build and deployment** בחרו **Deploy from a branch**, ענף `main` ותיקייה `/ (root)`, ולחצו **Save**.
6. כעבור דקה או שתיים הדף יהיה זמין בכתובת:

   ```text
   https://<שם-המשתמש>.github.io/<שם-המאגר>/
   ```

אחרי הפריסה אפשר גם "להתקין" את הדף כאפליקציה מתפריט הדפדפן, ולעבוד איתו כמו עם תוכנה רגילה.

> [!TIP]
> GitHub Pages מוגש ב-HTTPS, וזה התנאי להפעלת שמירה ישירה לקובץ. גם פתיחה מקומית בכרום (`file://`) עובדת.

## פרטיות ואבטחה

- אין בקשות רשת, אין CDN, אין גופנים חיצוניים ואין מעקב.
- התוכן נשמר רק אצלכם: בקובץ שבחרתם, ובטיוטה בדפדפן (`localStorage`).
- תוכן HTML בתוך המסמך עובר ניקוי לפני הצגה, וכתובות מסוכנות (כמו `javascript:`) נחסמות.
- ניקוי נתוני האתר בדפדפן מוחק את הטיוטה ואת ההפניה לקובץ האחרון.

## מגבלות ידועות

- אין עדיין לשוניות למסמכים מרובים.
- אין תמיכה בנוסחאות מתמטיות או בדיאגרמות (כמו Mermaid).
- ביטול ושחזור (`Ctrl+Z`) עובדים להקלדה רגילה ולהמשך רשימות, אך לא תמיד אחרי פעולות מסרגל הכלים או "החלף הכול".
- המשך הרשימות ב-Enter עשוי לא לעבוד במקלדות נייד מסוימות.
- הצבעה בבלוקי קוד גנרית, ללא ניתוח דקדוקי מלא.
